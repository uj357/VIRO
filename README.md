# DeskClock

تطبيق ساعة مكتبية بواجهة أفقية، ومعلومات تشغيل الوسائط، واختصارات التطبيقات وإعدادات الجهاز.

## إنشاء APK من GitHub

1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد، على الفرع `main`.
2. افتح تبويب **Actions** في المستودع.
3. اختر **Build APK** ثم اضغط **Run workflow**، أو انتظر البناء التلقائي بعد رفع الملفات.
4. بعد نجاح البناء، افتح نتيجة التشغيل (workflow run) ونزّل الملف **DeskClock-apk** من قسم **Artifacts**.
5. فك ضغط الملف وثبّت `app-debug.apk` على جهاز Android.

## متطلبات البناء

- JDK 17
- Android Gradle Plugin 8.5.2
- Gradle 8.7
- Android SDK 34

يتم تجهيز هذه المتطلبات تلقائياً بواسطة GitHub Actions في الملف `.github/workflows/build.yml`.

## ملاحظات على التثبيت

- الحد الأدنى للنظام هو Android 7.0 (API 24).
- للسماح بعرض معلومات Spotify والتحكم بالميديا، فعّل صلاحية **Notification access** للتطبيق.
- التطبيق يطلب أن يكون مشغّل الشاشة الرئيسية (Home app) حتى يعمل كلانشر.
- الملف الناتج `app-debug.apk` نسخة Debug موقعة بمفتاح الاختبار؛ مناسبة للتجربة والتثبيت الشخصي، وليست نسخة Release للنشر على المتجر.
